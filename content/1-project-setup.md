# Project Setup
A fundamental workflow in QGIS is setting up your project. This includes gathering data, creating and saving a new QGIS Project, loading your data to this project, and adding a basemap. The following pages will guide you through these steps in detail. Then, you'll be shown how to explore these layers and perform basic vector analysis to answer spatial questions.
